# CodeXtreme – UI Reconstruction Challenge (Question 1)

## 📘 Problem Statement

You are provided with **scrambled HTML and CSS code blocks** that together form an **Account Settings** user interface.

Your task is to **rearrange, merge, and correct the given code only** to reproduce the exact UI shown in the **sample output screenshot**.

⚠️ **No new code, files, or scripts may be added.**

---

## 🚫 Strict Rules

- ❌ JavaScript is **NOT allowed**
- ❌ Do NOT add `<script>` tags or external JS files
- ❌ Do NOT write new logic or event handlers
- ❌ Do NOT use frameworks (Bootstrap, Tailwind, etc.)

✅ **You may ONLY:**
- Reorder the scrambled code blocks  
- Move CSS rules to correct positions  
- Fix minor syntax or structural issues  
- Correct class nesting and hierarchy  
- Adjust existing CSS values if required  

---

## 🖼️ Expected Output Description

The final webpage must visually match the **provided sample output screenshot**.

  - Soft box shadow  

---

### 🔹 Header Section

- Buttons:
  - **Save Changes** (Primary – blue)
